MEDIAART 3D03: Study guide

Both the in-term exam and the final registrar-scheduled exam consist of 40 multiple choice questions, 5 in each of the 8 practices. To receive credit in the course for successfully achieving a practice on an exam, you'll need to answer 80% of the questions about that practice correctly (4 or 5 out of 5). If you don't successfully achieve a practice on the in-term exam, then the final registrar-scheduled exam would be your second chance to do that (to receive credit you just need to demonstrate a practice on either exam). Here are the things from each practice that are most likely to be the focus of a multiple-choice question:

Practice #1 - Terminals: navigate UNIX terminals/filesystems to make/change web projects

  • the concept of a present working directory, the pwd command, the ~ alias
  • making, removing, and entering directories (mkdir, rmdir, cd)
  • questions about absolute and relative filepaths

Practice #2 - Servers: run and interact with local/self-configured web servers

  • meaning of different parts of a URL
  • absolute and relative filepaths in URLs

Practice #3 - Codes: translate and do creative things with everyday computing/web codes (e.g. binary, ASCII, Unicode, QR codes

  • converting binary numbers to decimal and vice versa
  • basic characteristics of the ASCII code
  • relationship of ASCII to Unicode

Practice #4 - Web 1.0: read, write, and alter web pages/interfaces expressed in HTML and CSS

  • identifying well-formed HTML
  • using CSS to apply style information to specific HTML elements via classes and ids
  • application of CSS flexbox vs. grid

Practice #5 - JavaScript: read, write, and call simple JavaScript functions

  • questions about purpose of basic JavaScript elements (variables, functions, arrays, loops)
  • examples of simple JavaScript excerpts, identifying what happens when

Practice #6 - Web APIs: read and write JavaScript for the web browser

  • questions about getting information into and out of JavaScript dictionaries
  • examples of simple HTML/JavaScript integrations and identifying what happens when

Practice #7 - "Chat": use JavaScript to parse text input and generate text output

  • questions involving identifying the result of string/text manipulation functions

Practice #8 - Libraries: use specific JavaScript libraries to engage with additional visual possibilities and/or database-driven websites

  • questions about the purpose of libraries (in general), and about the purpose of the four libraries we explored
  • questions about the purpose of markdown
  • examples of JavaScript excerpts that use libraries, identifying how/where the library is imported
