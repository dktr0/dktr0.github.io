MEDIAART 3D03: JavaScript in the browser practice submission (practice #6)

Using nano from the terminal, and typing things one character at a time, create a webpage that demonstrates all three of HTML, CSS, and JavaScript. The project does not need to be large or fancy but must demonstrate originality, a creative idea, etc somehow (don't overthink this - just do something!). The HTML, CSS, and JavaScript must be (mostly) separated into three separate files called index.html, style.css, and code.js (as demonstrated in the lecture/full-class meeting), and all three should be in a named folder. To submit the project, zip that folder (the folder as a whole, not just the contents) and submit it in the dropbox on Avenue.

Just a thought: if you want to incorporate ASCII art into a webpage, check out the notes at the end of the ASCII art page
