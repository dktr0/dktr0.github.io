# [MEDIAART 3D03](../outline/index.html): Chat practice submission (practice #7)

Using nano from the terminal, and typing things one character at a time, create a small, original piece of software that features a REPL (read evaluate print loop) that responds differently to different input by the user (like the ELIZA or adventure game examples discussed in class). You can implement it using just node.js in the terminal, along the lines of the [model for a terminal-based REPL via node](../node-repl/index/html), or you can implement it in the browser - where there is the possibility for creative styling via HTML and CSS, along the lines of the [model for a REPL in the browser](../browser-repl/index.html). There is no need to make it super fancy - the important thing is that you understand each element of code (each "word", each symbol, each line) and that you are able to change and add to it while holding on to that understanding.

To submit on Avenue, please ZIP your working folder into a ZIP file (zip the whole folder not the individual files), then submit it in the relevant dropbox on Avenue. That's it!
