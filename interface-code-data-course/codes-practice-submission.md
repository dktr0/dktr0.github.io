# [MEDIAART 3D03](../outline/index.html): Codes practice submission (practice #3)

Using nano from the terminal, create a small (or not-so-small if you feel like it) piece of ASCII art, save it as a text file with the extension .txt (for example, myAsciiArt.txt), and submit it in the relevant folder on Avenue. That's it!
