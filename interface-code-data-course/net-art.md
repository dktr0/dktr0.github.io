# [MEDIAART 3D03](../outline/index.html): net.art

The [wikipedia article](https://en.wikipedia.org/wiki/Net.art) is a great starting point for learning about net.art.

Here are three artists whose work I like to share with people:
- [Jodi.org (duo of 2 artists)](https://wwwwwwwww.jodi.org/)
- [Vuk Ćosić](http://www.ljudmila.org/~vuk/)
- [Olia Lialina](https://art.teleportacia.org/)

Alexander R. Galloway has a 2016 article about Jodi and net.art - here's a quote I like from that article: "The true subject of the work is infrastructure—the cables and lines, the standards and protocols, all the industrial transfer technologies that reside in the space beyond the screen."

I could swear I visited wwwwwwwww.jodi.org sometime in the past few years and noticed the use of the obsolete html blink tag. Visiting it in Fall 2026, I notice that some simple JavaScript code is reimplementing the obsolete functionality of the blink tag, which is an interesting moment/feature to think about.

A really good exercise - both for learning about what the web browser (especially the web browser of the late 1990s) can do and for thinking about the specific pieces and their interpretation/significance - is to visit net.art pages and then use the web browser's "View Page Source" functionality (usually accessed by right clicking somewhere on a given page). In one of our class meetings, we'll do that a bit with net.art pages...
