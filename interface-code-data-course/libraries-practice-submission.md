# [MEDIAART 3D03](../outline/index.html): Libraries practice submission (practice #8)

Using the terminal and nano, create a small website project that explores one of the following libraries (discussed and practiced in our class meetings):

- [Punctual (as a library)](../punctual-in-a-website/index.html)
- [textmode.js](../textmode.js/index.html)
- [three.js](../three.js/index.html)

To submit on Avenue, ZIP your entire project folder and submit that in the Avenue drop box. For textmode.js and three.js, you can delete the node_modules subfolder if you like (to make the ZIP file smaller) - the necessary modules can always be regenerated later with ```npm i```.
